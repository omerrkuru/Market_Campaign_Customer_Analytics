# Market Campaign Customer Analytics and Response Prediction

## Project Overview

This project analyzes customer behavior using a market campaign dataset. The main objective is to understand customer profiles, purchasing habits, campaign response behavior, and to predict whether a customer will respond to a marketing campaign.

The project includes:

- Exploratory Data Analysis (EDA)
- CRM-based customer behavior analysis
- RFM customer segmentation
- Machine learning models for campaign response prediction

The target variable is `Response`, which indicates whether a customer responded to the latest marketing campaign.

---

## Business Problem

Marketing campaigns become more effective when they are targeted to the right customer groups. Instead of sending campaigns to all customers, companies can use customer data to identify customers who are more likely to respond.

This project aims to support data-driven marketing decisions by analyzing customer characteristics and building machine learning models to predict campaign response.

---

## Dataset

The dataset contains customer demographic information, income and family structure, product category spending, purchase channel behavior, previous campaign acceptance history, complaint information, and campaign response status.
